Cygnus v8 Host-Aware AutoMouse Gesture Visualizer

BT0/BT1 = Mac、BT2〜BT4 = Windows。スクロールはエンコーダ、AutoMouseは文字入力なしのマウス/ジェスチャーモード。D/M/Gの方向ジェスチャーはhold-tap + internal gesture layer + input processorで接続済み。

Host同じ物理操作=同じ意味。MacはCmd系、WindowsはCtrl/Win系。
実装状態D/M/G方向判定は AutoMouse上の &mg hold-tapで内部gesture layerを一時有効化し、cygnus,input-processor-gesture がtick=18 / wait-ms=500で方向ショートカットを発火。release時one-shotではないため実機で感度調整が必要。

AutoMouseL4維持。D/M/G位置を &mg hold-tapにして内部gesture layerを有効化。文字入力はしない。
Text ReturnAutoMouseから文章入力へ戻る時は、かな/英数を明示タップ。
Scroll layer廃止。PMW3610の scroll-layers=<5> も削除。
